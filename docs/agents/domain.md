# Domain Docs

This is a single-context repository.

When exploring, read `CONTEXT.md` at the repository root if it exists, then read relevant ADRs under `docs/adr/`. If either is absent, proceed without treating the absence as an issue.

Use the project's glossary vocabulary from `CONTEXT.md` in issue titles, specifications, refactor proposals, and tests. If a required concept is not defined, note the terminology gap for domain modeling.

Surface conflicts with existing ADRs explicitly instead of silently overriding them.
