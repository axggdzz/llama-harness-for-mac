## 二、全局统一规范（强制落地，全站生效）

所有UI组件必须遵循以下全局规范，杜绝局部样式混乱。

### 2\.1 布局基础规范

- 布局模式：固定栅格布局，严格匹配原图分栏比例、模块停靠层级

- 全局间距：统一内边距、外边距、模块间距，禁止随意留白

- 对齐规则：所有模块左对齐/居中对齐/右对齐严格对标原图，无错乱偏移

- 卡片规则：统一圆角、描边、阴影、背景透明度，全站视觉统一

### 2\.2 配色体系（完全对标原图科技深色主题）

采用原图同款**深色通透科技风配色**，所有色值固定，禁止自定义颜色：

- 页面背景：深灰通透底色，低饱和磨砂质感

- 卡片背景：半透明磨砂深色面板，轻微高斯模糊质感

- 主色调：原图同款浅蓝科技主色（高亮、选中、按钮、数据高亮）

- 文字层级：
        

    - 一级标题：高亮浅白

    - 二级正文：浅灰色常规字重

    - 辅助说明：浅灰弱化文字

    - 数据高亮：主色强调色

- 边框分割线：低饱和浅灰透明细边框，无粗边框、无黑边框

- hover 态：轻微提亮\+透明底色悬浮效果，无突兀变色

### 2\.3 字体与排版规范

- 字体家族：统一无衬线科技字体，全局一致

- 字号层级：严格区分标题、正文、辅助文字、数据文字字号

- 字重规范：标题加粗、正文常规、辅助文字轻量化

- 行高规范：统一宽松行高，杜绝文字拥挤、排版压抑

### 2\.4 卡片视觉质感规范（修复廉价扁平问题）

- 圆角：统一原图同款大圆角，无直角、无过小圆角

- 描边：1px 透明浅边框，保留轮廓层次

- 阴影：弱柔和下层阴影，营造悬浮通透感

- 背景：磨砂半透明，不纯白、不纯黑，贴合原图深色通透风格

## 三、精准量化UI参数规范（可直接代码落地）

本章节为**原图1:1复刻硬性量化参数**，全站UI禁止自定义数值、禁止近似取值，所有颜色、字号、间距、圆角、阴影、边框严格按以下固定值开发。

### 3\.1 精准色值体系（深色科技磨砂主题 Hex 固定值）

适配原图低饱和、通透、无刺眼高对比的专业控制台视觉风格。

- **页面全局背景**：`#0F1117`（深空深灰底，纯黑替代色，适配阴影层级）

- **卡片面板背景（常规）**：`#161A23`（磨砂半透深色面板）

- **底部状态栏面板背景**：`#1A1F29`（略高于普通卡片层级，突出底部状态栏）

- **主题主色（高亮/选中/数据强调/按钮）**：`#40A9FF`（原图同款浅蓝科技主色）

- **文字层级色值**一级标题/重点文本：`#F5F7FA`（高亮浅白）

- 二级正文/常规文本：`#C9CDD4`（标准浅灰正文）

- 辅助说明/备注文本：`#86909C`（弱化浅灰）

- 数据高亮数值：`#40A9FF`（主色强调）

**状态语义色值**空闲/正常：`#52C41A`（浅绿）

繁忙/加载：`#FAAD14`（浅黄）

异常/离线：`#F53F3F`（浅红）

**边框/分割线**：`rgba(255,255,255,0.08)`（透明细分割线，无粗黑边框）

**Hover悬浮底色**：`rgba(255,255,255,0.05)`

**选中激活底色**：`rgba(64,169,255,0.12)`

### 3\.2 全局字体量化规范

- **字体家族**：Inter, system\-ui, \-apple\-system, 微软雅黑, sans\-serif（全局统一无衬线科技字体）

- **字体层级固定参数**区块大标题：18px、字重600、行高1\.4、字间距0\.2px

- 卡片小标题：16px、字重500、行高1\.4、字间距0\.1px

- 常规正文数据：14px、字重400、行高1\.5、字间距0px

- 辅助备注文本：12px、字重400、行高1\.5、字间距0\.1px

### 3\.3 间距量化规范（全站统一留白）

- **页面全局边距**：左右 16px、顶部 16px、底部 24px

- **卡片内边距（padding）**：统一 16px

- **模块纵向间距**：卡片与卡片间距 12px

- **模块内部小标题与内容间距**：12px

- **列表/表格行内间距**：上下 8px、左右 12px

- **底部状态栏三栏间距**：均分自动适配，栏内边距 16px

### 3\.4 卡片视觉质感量化参数（彻底解决廉价扁平）

- **圆角半径**：统一 12px（原图同款大圆角，禁止直角/8px小圆角）

- **边框宽度**：1px，边框色 `rgba(255,255,255,0.08)`

- **阴影参数**：`0 4px 12px rgba(0,0,0,0.25)`（柔和下层悬浮阴影，营造通透层级）

- **背景模糊**：backdrop\-filter: blur\(8px\)（磨砂玻璃质感）

### 3\.5 底部 SideStatsPanel 精准量化参数

- 停靠属性：Dock=Bottom、固定悬浮、不随内容滚动

- 固定高度：**严格 200px（禁止自适应、禁止浮动高度）**

- 布局方式：水平三等分均分栏位

- 面板内边距：上下16px、左右20px

- 栏位间隔：12px

- 内部标题样式：16px/500/\#F5F7FA，底部距内容12px

- 内容数据样式：14px常规文本\+主色高亮数值

### 3\.6 交互状态量化规范

- Hover态：底色 `rgba(255,255,255,0.05)`、无变色、无缩放、无突兀高亮

- Active选中态：底色 `rgba(64,169,255,0.12)`、文字主色提亮

- 禁用态：透明度 0\.5、无交互、无hover响应
