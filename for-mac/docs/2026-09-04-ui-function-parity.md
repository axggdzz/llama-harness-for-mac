# macOS UI 功能对齐记录

本次补齐 macOS UI 与 Windows `LlamaHarness` 的主要功能路径，暂不调整颜色主题。

## 已对齐

- 保留七个中文页签：日志、统计、槽位绑定、槽位管理、系统资源、配置管理、信息展示。
- 配置管理页覆盖 macOS 后端配置模型：可执行文件、模型路径（自动维护 `--model` 参数）、参数数组、端口、就绪/轮询/Warming、闲置休眠、槽位数量、TokenGuard、上下文预算、思考模式、续接、崩溃恢复、自动强占、数据目录和日志选项。
- 右侧状态栏显示服务阶段、网关/后端状态、在途请求、运行时长、Token、槽位、Restore 命中率和思考模式；底部统计卡片继续保留。
- 日志页支持主日志、后端 stderr、警告/错误、请求 dump 及 `slot-N` 槽位日志，沿用 `/__logs__` 的轮转日志读取接口。
- 槽位管理保留 `/slots`、`/metrics` 原始探针以及 KV save/restore/erase/clear 操作。
- 闲置休眠选择“关闭”时写入 `idle_timeout_ms=0`，生命周期监视器不会自动停止后端。

## 有意保留的 macOS 差异

- Windows 的 P 核亲和、NVIDIA 显存和 `.exe` 浏览器不在 macOS 页面中伪造；后端参数使用 Unix 路径和参数数组。
- 配置保存后需要重启网关才能让监听端口、后端进程和日志目录等启动期设置完全生效，页面会明确提示。
- 颜色主题尚未作为本批次目标，后续可单独进行视觉复刻。
